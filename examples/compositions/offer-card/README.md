# Offer Card

A copyable example composition built from the public `Container`, `Text`, `ProgressBar`, `Separator`, and `Button` primitives. It does not read theme tokens or accept a theme prop; the surrounding `StyleProvider` supplies the active theme automatically.

The product artwork is fixture data and remains application-owned. The sample uses Roblox asset `77308658910524`, ported from the previous `bytespell-org/rbxcn` Offer Card review fixture (`healers-pack-hero.png`, SHA-256 `3768a3465226dee5d2d882be186c076107bf37180ceb5bb74a19c7640f6ce121`).

Examples are source you can copy and adapt. They are not exported from the package root and are not part of the primitive API compatibility contract.
