# Offer Card assets

`currency-coin.png` is the transparent source artwork for the Offer Card's
fantasy currency icon. It is published for the local Studio capture fixture as
`rbxassetid://107277852111449`.

The icon was generated as a polished gold medallion with an embossed crown,
then reduced to 512×512 while preserving its alpha channel. Public distribution
requires the image to be uploaded under the final oof/ui owner with appropriate
experience permissions.
